# 📊 SQL_practice

This repository contains practical SQL exercises and solutions completed while taking a data analytics course. It is designed to reinforce SQL fundamentals through real-world tasks such as filtering, aggregation, joins, subqueries, and table management.

## 🔍 What's inside?

- ✅ SQL basics: `SELECT`, `WHERE`, `GROUP BY`, `ORDER BY`
- 🔢 Filtering data: `BETWEEN`, `IN`, `LIKE`, `IS NULL`, `DISTINCT` 
- 🧮 Aggregation functions: `COUNT()`, `SUM()`, `AVG()`, `MIN()`, `MAX()`
- 🔗 Working with multiple tables: `JOIN`, `UNION`, subqueries, nested queries
- 📁 Table management: `CREATE`, `ALTER`, `DROP`, `INSERT`, `UPDATE`, `DELETE`
- 🧩 CASE statements & conditional logic
- 🧱 CTEs (Common Table Expressions) and temporary result sets using `WITH`
- 🕵️ Data exploration: `LIMIT`, `OFFSET`, sorting, and filtering patterns
- 🧠 Practice tasks similar to real interview questions and business use cases
- 📊 Real-world data analysis problems and SQL challenges
- 🛠 Schema design basics and best practices for structuring SQL queries

- ## 🛠 Technologies

- **SQL** – syntax mostly based on PostgreSQL / MySQL
- **DBeaver** – main database client for querying, editing, and testing SQL code
- **pgAdmin** – graphical user interface for managing PostgreSQL databases
